# 惩罚游戏

**在线玩：https://joewang911.github.io/punish-game/**

手机浏览器打开就能玩，可以添加到主屏幕。不用装东西，不用挂梯子。

一个情侣惩罚游戏。开盲盒抽卡，输了就做，做不到就付代价。
纯前端，没有后端，没有依赖，也可以下下来双击 `index.html` 离线玩。

## 玩法

三个盒子挑一个。里面可能是：

- **真心话** —— 写下来的答案会存进「真心话」，以后能翻出来看
- **大冒险** —— 带 ⏱ 的会弹倒计时，时间到就停
- **惩罚** —— 认吧
- **一起** —— 两个人一起做
- **反转 / 幸运** —— 把卡甩给对方，或者白拿一张免罚卡

做不到可以点「认输」抽一张代价卡。躲得掉，但是要付钱。

**点菜**里可以指定类型，还有一个 🎰 **动手**：两个转轮分开转，
上面出动作（亲、摸、舔、含……），下面出部位（嘴唇、锁骨、大腿内侧……），
合起来就是一张卡。当前尺度下最多 780 种组合，尺度越低露骨的部位越少，
而且**越高档的词越容易出现**（权重 2^(等级-1)），不然等级一开高，狠的组合反而被稀释。

每做完一张加一点热度，**每满 8 点解锁一次「终极」**。终极盲盒里只有最狠的那几张，
而且是**对方替你抽**。这是设计。

## 尺度

开局选一档，卡池按等级加权，越玩越热：

| | |
|---|---|
| 🌤 暖场 Lv1 | 刚在一起，还放不开，先聊点真的 |
| 🔥 暧昧 Lv1–2 | 动手动脚，衣服还在 |
| 💋 灼热 Lv1–3 | 开始脱，开始出声 |
| 🌋 失控 Lv1–4 | 今晚不设限 |

## 安全词

开局自己设，默认「菠萝」。游戏页最下面那行，点一下立刻全场停止，改成抱六十秒。

**不用解释，不算认输。** 这一条比上面所有玩法都重要。

## 红线

第二页是红线清单，默认全都允许。点一下变灰，那一类卡就不会出现在牌堆里
（留印子、绑手、蒙眼、拍照、冰块、吃的、命令、外面、声音）。

两个人各点各的，不用解释，游戏里也能随时改。

## 改卡池

`js/cards.js`。写法约定，看清楚了：

- **你** = 抽到这张卡的人
- **{other}** = 另一个人，会自动换成对方的名字
- 别用「我」指人，会搞混

格式：

```js
{ t: 'dare',   x: '凑到 {other} 耳边说句话。' },
{ t: 'punish', x: '手绑上，想要就开口求。', s: 60, p: ['丝巾或领带'], g: ['绑缚'] },
```

`t` 类型 · `x` 正文 · `s` 限时秒数 · `p` 要用的道具 · `g` 标签（对应红线清单）。

`SPECIAL.lucky` 的前三张带实际效果，改文案可以，别调顺序。

老虎机的词表在 `js/cards.js` 最下面的 `window.SLOT`，加词只要加一行：

```js
{ x: '用鼻尖蹭', lv: 2 },
{ x: '大腿内侧', lv: 4 },
```

`lv` 是它在哪一档尺度开始出现，`g` 是红线标签（比如「吸」标了 `痕迹`，关掉痕迹就抽不到）。

## 存档

存在浏览器的 localStorage 里，重开页面会有「接着上一局」。

用 `file://` 双击打开时，Chrome / Edge / Firefox 都能存；Safari 会禁掉，那就只是不留记录，游戏照玩。
部署到 GitHub Pages 用 https 打开就没有这个问题。

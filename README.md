# 惩罚游戏

**在线玩：https://joewang911.github.io/punish-game/**

手机浏览器打开就能玩，可以添加到主屏幕。不用装东西，不用挂梯子。

一个情侣惩罚游戏。纯前端，没有后端，没有依赖，也可以下下来双击 `index.html` 离线玩。

## 玩法

**每一手分两步。**

**第一步，转盘定类型。** 转到什么这把就玩什么：

- 💬 **真心话** —— 写下来的答案存进「真心话」，**跨局永久保留**
- 🎯 **大冒险** —— 带 ⏱ 的会弹倒计时，时间到就停
- ⚡ **惩罚** —— 认吧
- 💞 **一起做** —— 两个人一起
- 🎰 **翻牌子** —— 两个转轮分开转，上面出动作、下面出部位，自己组合

**第二步，按类型抽盲盒。** 三个盒子挑一个，抽到该类型的一张具体卡。
转到**翻牌子**就不用抽盒了，直接进那两个转轮。

开盒的时候还有两次小判定：

- **4% 反转** —— 这一张转给对方做，**对方做完对方 +1 分**
- **4% 幸运** —— 这轮免罚，直接跳过

做不到可以点「认输」抽一张代价卡。躲得掉，但是要付钱——**代价做完积分直接 +2**。

## 谁受罚

**默认轮流，但你可以直接点上面那个人的名字换人。**

所以别的游戏输了、想罚谁，直接点他就行——不用管轮到他没有。
拿不定主意就用 🎲 **谁受罚**：各掷两颗骰子，小的抽惩罚，平手就一起做。

## 终极模式

**谁的积分先攒到 4 张，他下次受罚时就进终极模式。**

进终极模式之后，主动权整个交出去：

- **由对方**指定玩五种模式里的哪一种
- 三个盒子的内容**全部摊开**给对方看，对方挑一个给你
- 选**翻牌子**的话，动作和部位也**由对方一个个点**

积分每到 4 的倍数（4、8、12…）就再触发一次，所以先到 4 的那个人先享受。

## 等级

**每次开局的页面上有个等级按钮，显示当前出的是哪一档的题。点它随时能换，题目立刻跟着换。**

题目**严格按等级出**——选 Lv4 就只有 Lv4，选 Lv1 就只有 Lv1，不会混。
翻牌子也一样，只出当前档的词。

两个人加起来做满 **16 张**，会问你一次要不要升一档（Lv4 就不用问了）。

| | |
|---|---|
| 🌤 暖场 Lv1 | 刚在一起，还放不开，先聊点真的 |
| 🔥 暧昧 Lv2 | 动手动脚，衣服还在 |
| 💋 灼热 Lv3 | 开始脱，开始出声 |
| 🌋 失控 Lv4 | 仅限成年情侣；更大胆，但每一步都要双方愿意 |

每档可抽的量：

```
Lv1  39 张 · 翻牌子 9 动作 × 10 部位
Lv2  41 张 · 翻牌子 8 动作 ×  9 部位
Lv3  38 张 · 翻牌子 9 动作 × 10 部位
Lv4  73 张 · 翻牌子 10 动作 × 10 部位
```

## 安全词

开局自己设，默认「菠萝」。游戏页最下面那行，点一下立刻全场停止，改成抱六十秒。

**不用解释，不算认输。** 这一条比上面所有玩法都重要。

本游戏仅限成年人自愿参与。选择了某个尺度或没有说安全词，都不代表自动同意后续所有动作；
任何一方都可以随时要求「慢一点」「换一个」或「停」，沉默不等于同意。涉及拍摄、绑缚、
留痕和支配的卡，开始前必须再次得到明确同意。

高强度玩法统一使用「绿 / 黄 / 红」：绿是继续，黄是立刻减轻或调整，红是立即停止并解除束缚。
拍打只允许使用手掌接触双方事先同意的安全部位，避开头、颈、脊柱、腰肾和关节；不以疼痛、
留伤或破皮为目标。禁止掐脖子、窒息、武器和醉酒参与。结束后要解除束缚、补水并确认彼此状态。

## 红线

第二页是红线清单，默认全都允许。点一下变灰，那一类卡就不会出现在牌堆里
（留印子、绑手、蒙眼、拍照、冰块、吃的、命令、外面、声音、明确性行为、拍打）。

两个人各点各的，不用解释，游戏里也能随时改。

## 结束和存档

菜单里的 **🏁 结束这一局** 会给你一份小结（谁做了几张、一共多少热度），然后：

- **本局记录清空**，分数和热度归零
- **「真心话」永久保留**，跨局一直留着，下次还能翻

这两件事是分开的，因为真心话是这游戏唯一值得留下来的东西，不该被重开冲掉。

**🗑 清空所有数据** 才是真的全删，包括所有真心话，会二次确认。

中途关掉页面不要紧，下次打开首页会有「接着上一局」。

## 改卡池

`js/cards.js`。写法约定，看清楚了：

- **你** = 抽到这张卡的人
- **{other}** = 另一个人，会自动换成对方的名字
- 别用「我」指人，会搞混

格式：

```js
{ t: 'dare',   x: '凑到 {other} 耳边说句话。' },
{ t: 'punish', x: '手绑上，想要什么就开口求。', s: 60, p: ['丝巾或领带'], g: ['绑缚'] },
```

`t` 类型 · `x` 正文 · `s` 限时秒数 · `p` 要用的道具 · `g` 标签（对应红线清单）。

`SPECIAL.lucky` 的前三张带实际效果，改文案可以，别调顺序。

翻牌子的词表在同一文件最下面的 `window.SLOT`：

```js
{ x: '用鼻尖蹭', lv: 2 },
{ x: '大腿内侧', lv: 4 },
```

`lv` 是它在哪一档尺度开始出现，`g` 是红线标签（比如「吸」标了 `痕迹`，关掉痕迹就抽不到）。

# 惩罚游戏

**在线玩：https://joewang911.github.io/punish-game/**

手机浏览器打开就能玩，可以添加到主屏幕。不用装东西，不用挂梯子。

一个情侣惩罚游戏。纯前端，没有后端，没有依赖，也可以下下来双击 `index.html` 离线玩。

## 玩法

**每一手分两步。**

**第一步，转盘定类型。** 转到什么这把就玩什么：

- 💬 **真心话** —— 写下来的答案存进「真心话」，**跨局永久保留**
- 🎯 **大冒险** —— 带 ⏱ 的会弹倒计时，时间到就停
- ⚡ **惩罚** —— 认吧
- 💞 **一起做** —— 两个人一起
- 🎰 **翻牌子** —— 两个转轮分开转，上面出动作、下面出部位，自己组合

**第二步，按类型抽盲盒。** 三个盒子挑一个，抽到该类型的一张具体卡。
转到**翻牌子**就不用抽盒了，直接进那两个转轮。

**转盘的五种玩法概率一模一样，各占 72°。** 另外还有一次极小的判定（各 4%），
会截胡掉这把的结果——**这两张不画在盘上**：

- **反转** —— 指针停在哪一格不重要，这一把整个归对方，对方做完对方 +1 分
- **幸运** —— 这轮免罚，直接跳过

做不到可以点「认输」抽一张代价卡。躲得掉，但是要付钱——**代价做完积分直接 +2**。

## 卡上现场掷一次

有些卡会让你**当场掷一次**，卡片上会自动出现按钮，结果直接显示：

- 🎲 **两颗骰子** —— 例如「和对方各掷两颗，点数小的脱一件」
- 🪙 **三枚硬币** —— 例如「反面朝上几次，就脱几件」

掷完可以重掷，再点「做了」正常结算。

## 谁受罚

**默认轮流，但上面两个人的名字可以直接点，点谁就是谁。**

所以别的游戏输了、想罚谁，直接点他就行——不用管轮到他没有。
拿不定主意就用 🎲 **谁受罚**：各掷两颗骰子，小的抽惩罚，平手就一起做。

## 终极模式

**谁的积分先攒到 4 张，他下次受罚时就进终极模式。**（每到 4 的倍数再触发一次）

这个环节整段在页面上演，不弹窗：

1. **先问这次谁受罚**，默认是攒够的那位，**但可以改成对方**——要连坐就点对方
2. **由对方**指定玩五种模式里的哪一种
3. 三个盒子**依次炸开**，内容全部摊在桌面上，对方挑一个给你
4. 选**翻牌子**的话，动作和部位由对方**滑着选**（左右滑动，停在中间的那个就是选中）

积分每到 4 的倍数就再触发一次，所以先到 4 的那个人先享受。

## 等级

**每次开局的页面上有个等级按钮，显示当前出的是哪一档的题。点它随时能换，题目立刻跟着换。**

题目**严格按等级出**——选 Lv4 就只有 Lv4，选 Lv1 就只有 Lv1，不会混。
翻牌子也一样，只出当前档的词。

两个人加起来做满 **16 张**，会问你一次要不要升一档（Lv4 就不用问了）。

| | |
|---|---|
| 🌤 暖场 Lv1 | 还放不开，先聊点真的。只聊天、握手、拥抱 |
| 🔥 暧昧 Lv2 | 动手动脚，**衣服还在**。亲亲抱抱摸，隔着衣服 |
| 💋 灼热 Lv3 | **开始脱**，露出皮肤，碰敏感部位，会出声 |
| 🌋 失控 Lv4 | 没有尺度限制。用嘴、用手、进来、绑住、拍打、晾着、不许自己去 |

每档可抽的量：

```
Lv1  48 张 · 翻牌子  9 动作 × 10 部位
Lv2  58 张 · 翻牌子  9 动作 ×  9 部位
Lv3  60 张 · 翻牌子  9 动作 × 10 部位
Lv4  98 张 · 翻牌子 12 动作 × 12 部位
合计 264 张
```

## 安全词

开局自己设，默认「菠萝」。游戏页最下面那行，点一下立刻全场停止，改成抱六十秒。

**不用解释，不算认输。** 这一条比上面所有玩法都重要。

仅限清醒的成年人自愿参与。**安全词是唯一的刹车**——谁说出来，游戏立刻停，抱六十秒，
不用解释，不算输。除此之外没有「慢一点」「换一个」，愿赌服输，卡上怎么写就怎么做。

只有三条，跟尺度无关，只跟「别进医院」有关：

- 不碰脖子，不做呼吸限制
- 绑住的东西必须能在两秒内解开
- 不留下会破皮见血的伤

这三条不是审查，是这三样东西真的会把人送进急诊。其余全部放开。

高强度环节结束后最好互相解开、喝水、抱一会儿——不是规矩，是这么玩才玩得长久。

## 红线

第二页是红线清单，默认全都允许。点一下变灰，那一类内容就不会出现在牌堆里。
两个人各点各的，不用解释，游戏里也能随时改。

十二个标签，每个回答一个不同的问题（双数，界面两列刚好排满）：

| 标签 | 回答的问题 |
|---|---|
| **裸露** | 会脱到什么程度 |
| **敏感部位** | 会碰哪里 |
| **性行为** | 会做到哪一步 |
| **用嘴** | 要不要用嘴做 |
| **听指令** | 谁说了算 |
| **留痕** | 明天会不会被人看出来 |
| **绑束** | 会不会被限制住 |
| **蒙眼** | 会不会看不见 |
| **道具** | 要不要额外东西 |
| **影像** | 会不会被留影 |
| **被听见** | 会不会被外人察觉 |
| **疼痛** | 会不会疼 |

**每个标签都有「最早能从哪一档出现」的限制，而且是测试强制的**——
Lv2 绝不会出现「裸露」，Lv3 绝不会出现「性行为」。这条如果破了，测试直接报错。

打标原则是**只标「这张卡明确且主要在做这件事」**，顺带提到的不算——
比如一句情话里出现了「亲」，不该标敏感部位。

264 张卡里有 172 张带标签，剩下的是真·轻内容（聊天、拥抱、说心里话），
关掉全部标签它们仍然会出。**红线是精确屏蔽，不是安全模式。**

> 标签改过名，老存档会自动迁移（痕迹→留痕、绑缚→绑束、拍摄→影像、
> 冰块/食物→道具、支配→听指令、外面/声音→被听见、拍打→疼痛），
> 之前屏蔽过的不会莫名其妙失效。

## 结束和存档

菜单里的 **🏁 结束这一局** 会给你一份小结（谁做了几张、谁先攒够），然后：

- **本局记录清空**，分数归零
- **「真心话」永久保留**，跨局一直留着，下次还能翻

这两件事是分开的，因为真心话是这游戏唯一值得留下来的东西，不该被重开冲掉。

**🗑 清空所有数据** 才是真的全删，包括所有真心话，会二次确认。

中途关掉页面不要紧，下次打开首页会有「接着上一局」。

## 改卡池

`js/cards.js`。写法约定，看清楚了：

- **你** = 抽到这张卡的人
- **{other}** = 另一个人，会自动换成对方的名字
- 别用「我」指人，会搞混

格式：

```js
{ t: 'dare',   x: '凑到 {other} 耳边说句话。' },
{ t: 'punish', x: '手绑上，想要什么就开口求。', s: 60, p: ['丝巾或领带'], g: ['绑束', '听指令'] },
```

`t` 类型 · `x` 正文 · `s` 限时秒数 · `p` 要用的道具 · `g` 标签（对应红线清单）。

**加卡的时候注意等级边界**（这条有测试盯着）：

| 档 | 不许出现 |
|---|---|
| Lv1 | 敏感部位、裸露、性行为，以及一切身体接触之外的标签 |
| Lv2 | 裸露、性行为、用嘴 |
| Lv3 | 性行为、用嘴 |
| Lv4 | 不限 |

写错了测试会直接报「Lv2 出了『裸露』」这类错误，不会静默上线。

`SPECIAL.reverse` / `SPECIAL.lucky` 只是开盒时随机挑一句的文案池，不是卡。

翻牌子的词表在同一文件最下面的 `window.SLOT`：

```js
{ x: '用鼻尖蹭', lv: 2 },
{ x: '大腿内侧', lv: 4 },
```

`lv` 是它在哪一档开始出现，`g` 是红线标签（比如「吸」标了 `留痕`，关掉留痕就抽不到）。
